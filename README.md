# UI-UX-Experiment3

## Aim:

To perform heuristic evaluation of existing apps.

# Problem Statement:

Compare 2–3 competing apps and identify UX improvements.

## Algorithm:

1. Select 2–3 competitor apps
2. Perform heuristic evaluation
3. Identify UX issues
4. Apply improvements
5. Perform A/B testing

A heuristic evaluation was conducted on three competing music streaming applications: **Spotify, YouTube Music, and Amazon Music**. The apps were compared using Jakob Nielsen’s 10 Usability Heuristics, focusing on navigation, consistency, efficiency, recognition, and user control.

### Comparison and Analysis of User Experience

**Spotify:**

Spotify provides simple navigation and personalized recommendations. However, the home screen can feel crowded with multiple recommendations.

**YouTube Music:**

YouTube Music provides a large music library and powerful search. However, navigation between music and video content can sometimes feel inconsistent.

**Amazon Music:**

Amazon Music provides music, playlists, and podcasts. However, some features require more navigation and are less easily discoverable.

### Overall Observation

Spotify has better personalization, YouTube Music has better content variety, and Amazon Music provides multiple features. All three can improve navigation and content discovery.

### Proposed Improvements

Simplified navigation

Better content discovery

Reduced visual clutter

Clearer information

Faster playlist access

Unique Feature Introduced: A **Smart Compare** option to compare playlists and recommendations in one screen.

## A/B Testing

**Version A:** Existing interface.

**Version B:** Improved interface with better navigation and Smart Compare.

Version B showed faster task completion and better user satisfaction compared to Version A.

## Result

The redesigned interface improved navigation, content discovery, and overall usability. A/B testing showed that the proposed changes improved user behaviour and efficiency.
